# Exa Search Skill

**Canonical reference:** https://docs.exa.ai/reference/search-api-guide-for-coding-agents

If anything below looks outdated or contradicts real API behavior,
fetch that URL — it is the source of truth.

Use Exa when user asks to:
- Research competitors or existing products
- Find documentation for unfamiliar APIs/tools
- Analyze how other apps work before building
- Find design references or similar products

Exa search types:
- neural: semantic/conceptual search (default for research)
- keyword: exact term matching (for specific docs/APIs)

Always include contents: true to get full page text.
